# Pandas for Exploratory Data Analysis (EDA)

A hands-on learning repository focused on **Pandas**, one of the most essential Python libraries for data analysis and machine learning.

This repository covers the fundamentals of working with structured datasets, selecting and filtering data, performing aggregations, and cleaning messy data. It includes practical Python scripts, a Titanic dataset, exercises, and a quick-reference cheatsheet.

##  Topics Covered

- **Series:** Understanding Pandas Series and their operations.
- **DataFrames:** Creating, exploring, and manipulating tabular data.
- **Importing Data:** Loading datasets from CSV files.
- **Selection:** Selecting rows, columns, and specific values using `loc` and `iloc`.
- **Filtering:** Filtering datasets using conditions and Boolean masks.
- **Aggregation:** Summarizing data using functions such as `mean()`, `sum()`, `groupby()`, and `agg()`.
- **Data Cleaning:** Handling missing values, duplicates, and inconsistent data.

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/NerdBhattarai98/pandas-for-eda.git
```

### 2. Navigate to the project directory

```bash
cd pandas-for-eda
```

### 3. Install the required library

```bash
pip install pandas
```

### 4. Run a Python script

```bash
python 01_series.py
```

You can run the other scripts in numerical order as you progress through the topics.
